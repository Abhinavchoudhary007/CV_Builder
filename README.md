# Django Resume Builder

A Django-based web application that allows users to create, manage, view, and download professional resume profiles.

## 🚀 Features

- Submit resume data through a clean and responsive web form.
- Store profile data using Django's ORM.
- View a list of all created resume profiles.
- Download resumes as PDF files generated dynamically using `pdfkit` and `wkhtmltopdf`.
- Preview resumes as HTML pages.
- Delete profiles from the database.
- Fully responsive UI styled with Bootstrap and FontAwesome icons.

## 🛠️ Technologies Used

- **Backend:** Django (Python)
- **PDF Generation:** pdfkit, wkhtmltopdf
- **Frontend:** Bootstrap 4, HTML5, CSS3, FontAwesome
